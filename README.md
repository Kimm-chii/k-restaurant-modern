# Sora 空 — Modern Japanese Restaurant Concept

A modern Japanese restaurant website concept focused on creating a refined digital dining experience through simplicity, balance, and intentional design.

Inspired by Japanese Yohaku (余白), the project explores how thoughtful spacing, elegant typography, and interactive experiences can create a calm and memorable online presence.

## ✦ Core Focus

- **Interface Design**  
  Minimalist visual design inspired by Japanese aesthetics, focusing on balance, clarity, and intentional use of space.

- **Frontend Development**  
  Building responsive, high-performance interfaces with modern frontend technologies and a focus on smooth user experiences.

- **Interactive Experience**  
  Creating engaging interactions including menu filtering, glassmorphic capsule navigation, floating category browsing, and subtle motion effects.

## 🛠 Design & Development Process

This project was created through an AI-assisted creative workflow, using AI as a tool for exploration, prototyping, and iteration.

The creative direction, design decisions, implementation choices, and final experience were guided through human-led design thinking and refinement.

Key contributions include:

- Defining the visual direction and design system
- Creating UI layouts and user flows
- Customizing and refining components
- Implementing responsive interactions
- Optimizing the experience across devices
- Testing, refining, and deploying the final product
